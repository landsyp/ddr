Overview

DDR2 SaaS helps charities record gifts, maintain donor records, manage receiptable accounts, generate official receipt batches, export reports, and administer users inside an organization-specific workspace.

For operators

Add donors, record donations, search records, generate receipts, mark receipts sent, and export CSV files.

For administrators

Update organization profile fields, manage user access, add accounts, and control account receipt eligibility.

For SaaS workspaces

Each organization has isolated users, donors, accounts, donations, receipts, reports, and settings.

Important: The app keeps the original ColdFusion source for reference, but the working SaaS app runs from the React UI and Node/SQLite API.

Quick Start

Start locally

  1. Install packages with npm install.
  2. Start the app with npm run dev -- --host 127.0.0.1.
  3. Open http://127.0.0.1:5173/ in the browser.

Default development login

  • Email: admin@ddr.local
  • Password: password
  • The API runs at http://127.0.0.1:5174/.

Create a new organization workspace

  1. On the login screen, select Create organization workspace.
  2. Enter charity name, registration number, admin name, admin email, password, city, and phone.
  3. Use a password with at least 8 characters.
  4. Submit the form to create a new isolated SaaS workspace with default accounts.

Forgot password

Select Forgot password, enter the email address, and submit. The app confirms that reset instructions will be handled by the DDR administrator when the email belongs to an active user.

Donors

The Donors screen stores contact details, donor numbers, receipt preferences, member status, lifetime giving totals, and notes.

Add a donor

  1. Open Donors and use New donor or the Add Donor panel.
  2. Enter donor number or leave it blank to use the next available number.
  3. Enter first name, last name, email, address, city, postal code, province, phone numbers, and notes.
  4. Enable Member when the donor is a member.
  5. Keep Receipts enabled checked if donations for this donor should appear in receipt batches.
  6. Submit the form. The donor directory refreshes automatically.

Search, export, archive

  • Use Filter donors or the top search bar to find donors by number, name, email, or city.
  • Select CSV to download the current donor list as donors.csv.
  • Select Archive to hide a donor from active lists; select Activate to restore access.
  • Archived donors are not included in active receipt generation.

Donations

The Donations screen records gifts, assigns each gift to a donor and account, and displays receipt readiness.

Record a donation

  1. Open Donations.
  2. Select the donor and account.
  3. Enter amount, gift date, payment method, and optional description.
  4. Submit with Add donation.

Donation register

Status Meaning
Ready The donor and account both allow receipts, and no receipt has been issued yet.
Issued The donation has already been linked to a receipt.
No receipt The donor or the selected account is not eligible for receipts.

Delete a donation

Use the trash button in the register and confirm the prompt. The row is removed from the database for the active organization.

Accounts

Accounts group donations and control whether donations assigned to an account can generate official receipt amounts.

Add an account

  1. Open Accounts.
  2. Enter account number and account name.
  3. Check Eligible for receipts when gifts to this account should be receiptable.
  4. Submit with Add account.

Manage accounts

  • Select the Receiptable or No receipt pill to toggle eligibility.
  • Use the trash button to delete an account only when it has no linked donations.
  • If an account has donations, the API blocks deletion to protect historical records.

Receipts

The Receipt Center generates receipt batches from eligible donors and receiptable accounts for a selected date period.

Eligibility rule: A donation is included when the donor is active, the donor has receipts enabled, the account is receiptable, and the gift date falls within the selected period.

Generate a receipt batch

  1. Open Receipts.
  2. Choose start date and end date. The default period is January 1 to December 31, 2026.
  3. Choose Email or Print mode.
  4. Select Generate. The app creates one receipt per eligible donor for the period.

What generation does

  • Sums eligible gifts by donor for the selected period.
  • Replaces any existing receipt for the same donor and exact period.
  • Locks included donations by linking them to the generated receipt.
  • Creates an email/print delivery row and assigns receipt numbers from the delivery ID.
  • Shows a message when no eligible receipt rows exist for the period.

Receipt statuses

  • Email mode with valid email: status starts as In progress.
  • Email mode without valid email: status starts as Invalid email.
  • Print mode: status starts as To print.
  • Mark sent: updates the delivery status to delivered.

Batches

The Batches table groups generated receipts by creation time and period, showing count and total amount for each batch.

Reports

Reports are generated directly from the SQLite data for the active organization and can be exported to CSV.

Run a report

  1. Open Reports.
  2. Select report type: Donations, Donors, Accounts, or Receipts.
  3. For donation reports, choose grouping by date, account, donor, or method.
  4. Choose start and end dates when applicable.
  5. Select Run report.

Export report

After rows load, select Export to download ddr-report.csv. The export uses the rows currently returned by the report builder.

Settings & Users

Settings store the charity profile used by receipts, replies, and deposit-related organization fields. User management is available to administrators.

Organization profile

  • Organization name
  • Registration number
  • Contact name and contact email
  • Reply email
  • Phone, address, city, postal code, province
  • Currency, transit, folio
  • CQOC member flag and organization active flag

Select Update profile to save changes.

User management

  • Add first name, last name, email, and temporary password.
  • Use passwords with at least 8 characters.
  • Check Admin access to allow settings, accounts, and user management.
  • Deactivate or reactivate other users from the user table.

The current signed-in user cannot deactivate their own account from the table.

Admin-only: Profile updates, account creation/deletion, and user management require admin access.

Subscription Request

The Subscription screen stores access requests for CQOC follow-up. In the React app, it is available from the sidebar after login, and the API endpoint also accepts unauthenticated subscription request submissions.

Pricing shown in the app

Annual revenue CQOC member Non-member
$0 - $50,000 $60/year $70/year
$50,001 + $70/year $85/year

Submit a request

  1. Enter charity name, registration number, responsible person, email, address, city, province, and phone.
  2. Check CQOC member if applicable and enter the member number.
  3. Answer the security question 50 + 20 with 70.
  4. Submit the request. The record is stored in SQLite for follow-up.

Administrator Notes

Database and sessions

  • The default database is data/weserve.sqlite.
  • Use WESERVE_DATABASE_PATH=/path/to/weserve.sqlite to override the database location.
  • Session tokens are stored client-side in browser local storage and are sent as bearer tokens to the API.
  • Sessions expire after approximately 30 days.
  • The server derives organization scope from the authenticated session, not from client-provided organization IDs.

SaaS administration

  1. Sign in as saas.admin@ddr.local to open the Tenants page and review all tenant organizations.
  2. Open Subscription to compare plans, switch monthly/annual billing, review usage limits, and complete the launch checklist.
  3. Open Settings → Payment methods to add a billing method and review invoice history.
  4. Open Settings → Security posture to require MFA, set password length, set session timeout, and restrict allowed email domains.
  5. Open Settings → API keys & Webhooks to create integration keys, copy one-time secrets, configure HTTPS webhook endpoints, and send test deliveries.
  6. Open Settings → Audit log to review tenant-level actions such as subscription changes, user updates, payment changes, key revocations, and receipt generation.

Role matrix

Role Scope Purpose
SaaS Admin All tenants Platform operator who can see the tenant overview and manage SaaS controls.
Organization Admin One organization Tenant owner who manages users, settings, billing, subscriptions, and workspace data.
Editor One organization Operational user who can maintain donors, donations, accounts, receipts, and reports.
Auditor One organization Read-only reviewer for reports, receipts, billing history, and audit events.
Viewer One organization Read-only user for dashboards and workspace records.

Troubleshooting

Issue What to check
Cannot log in Confirm email/password, active user status, active organization status, and license date.
Receipt generation creates zero rows Check that the period contains eligible gifts and confirm active donor status, donor receipt flag, and account receipt flag.
Donation cannot be added Confirm the selected donor and account belong to the active organization.
Account cannot be deleted Accounts with linked donations are protected. Keep the account and toggle receipt eligibility if needed.
User cannot be created Use a unique email address and a password with at least 8 characters.
Subscription form fails Answer the security question with 70 and ensure required charity/contact fields are filled.
